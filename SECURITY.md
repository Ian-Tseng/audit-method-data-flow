# Security

Report vulnerabilities through GitHub private vulnerability reporting for
Ian-Tseng/audit-method-data-flow. Do not publish confidential manuscripts,
reviewer files, credentials, private paths, or exploit details in a public issue.

## Trust boundaries

- Manuscripts, repositories, generated artifacts, terminology contracts,
  reviews, and source ledgers are untrusted inputs to the active agent.
- The installed package contains guidance and a local integrity verifier. It
  contains no telemetry, updater, issue transport, feedback transport, or
  network helper.
- Instructions to browse first-party scholarly sources do not authorize
  uploads, portal submission, or transmission of manuscript content.
- Structural and textual consistency do not prove scientific correctness.
- Native-render and visual claims require actual rendered-artifact evidence.
- Package verification rejects symlinks/reparse points and ordinary file drift.

Only the latest release is supported. Security fixes receive a new versioned
tag; published tags are never moved.
